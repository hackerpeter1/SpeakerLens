# SpeakerLens 系统展示

> Motivation: better Speaker Reco  
> Keywords: Speaker Reco, XAI

这个仓库用于展示 SpeakerLens 的核心功能：音频选择、图片结果、定位、解释、润色、对比和问询。

## 音频

GitHub 的 `README.md` 不能直接运行 JavaScript，因此交互式音频选择栏放在 GitHub Pages 页面中：

- 页面文件：`index.html`
- 音频路径示例：`assets/audio/sample-speaker-a.wav`
- 当前交互：点击不同音频选项后，页面会切换播放器并展示对应的 `audio source`
