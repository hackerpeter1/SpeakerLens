03 / KNOWN-AUDIO HIERARCHY & UNSEEN-AUDIO PATH

This hierarchy is built by a hierarchical clustering algorithm analysing the representation space of the speaker recognition network, trained on known audios. For a new sample, we trace where it lands, what path it takes through the hierarchy, and which cluster it is ultimately assigned to. As more known audios are analysed, more hierarchies are discovered within the representation space.

04 / IDENTIFICATION OF SECOND-ORDER SEMANTIC PATTERNS

A second-order pattern is a deeper pattern involved in the decision-making process of the first-order pattern recognition task (i.e. speaker recognition task). Concretely, each level of cluster in the hierarchy corresponds to one second-order pattern, and each second-order semantic pattern is what semantic attribute that cluster represents.

06 / LLM-POWERED Q&A
What's the connection between a second-order pattern and the speaker recognition decision?
A second-order pattern represents one cluster in the hierarchy, which typically has a sibling cluster. This second-order pattern is used to distinguish the speakers within its own cluster from the speakers in the sibling cluster.
How should I interpret the L-score?
The L-score reflects how confidently a sample is assigned to its cluster relative to other samples. A score of 0.73 means the sample sits more confidently in its cluster than roughly 27% of samples in the same cluster.
